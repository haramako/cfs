# CFS ドキュメント

CFS (Content base File System) は、ゲームのアセットのような大量のファイルを、変更があった分だけ効率よくアップロード・ダウンロードするためのツールです。

まず動かしてみたい場合は、ルートの [README](../README.md) を見てください。

## 使う人向け

| ドキュメント | 内容 |
|---|---|
| [仕組み](overview.md) | キャビネット・マニフェスト・タグの考え方、差分転送の仕組み、キャッシュ |
| [設定](configuration.md) | `.cfsenv`、環境変数、圧縮と暗号化、ローカルのキャッシュ |
| [コマンド](commands.md) | 全コマンドとオプションの説明 |
| [ストレージ](storage-backends.md) | ローカルと Amazon S3 の使い方、認証、必要な権限 |
| [パックファイル](pack-format.md) | 複数ファイルを1つにまとめる形式と、差分パッチの作り方 |
| [制限と注意点](limitations.md) | 知っておくべき挙動や、現在の制限 |
| [キャビネットの形式](format.md) | キャビネットの中身の決まり（マニフェスト、暗号化、署名）。cfs 以外から読むときの仕様 |
