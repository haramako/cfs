# コマンド

```
cfs [グローバルオプション] <コマンド> [オプション] [引数...]
```

`cfs -h` で一覧、`cfs help <コマンド>` で各コマンドの説明を表示できます。

コマンドのオプションは、引数の後ろにも書けます（`cfs upload src -t v1`）。グローバルオプションも、コマンドの後ろに書けます（`cfs upload -V src`）。

## グローバルオプション

| オプション | 既定値 | 内容 |
|---|---|---|
| `--verbose`, `-V` | | 詳しいログを表示します |
| `--config`, `-C` | `.cfsenv` | 設定ファイル |
| `--cabinet`, `-c` | | アップロード先の URL かパス（`.cfsenv` の `Cabinet` を上書き） |
| `--url` | | ダウンロード元の URL かパス（`.cfsenv` の `Url` を上書き） |
| `--force`, `-f` | | 手元のキャッシュを使わずに、全ファイルを調べ直してアップロードします |
| `--filter-cmd` | | 対象のファイルを絞り込むコマンド（[後述](#ファイルの絞り込み)） |
| `--setting`, `-S` | | 今は使われていません（設定は常に `~/.cfs_setting` から読みます） |
| `--help`, `-h` | | ヘルプを表示します |
| `--version`, `-v` | | バージョンを表示します |

## アップロード

### `upload`

```
cfs upload [-t タグ] [-m マニフェストの保存先] [-o ハッシュの出力先] [フォルダ...]
```

フォルダをアップロードします。フォルダを省略すると、今のフォルダ（`.`）が対象です。

| オプション | 内容 |
|---|---|
| `--tag`, `-t` | アップロードしたマニフェストにタグを付けます。使える文字は `A-Za-z0-9._-` です |
| `--manifest`, `-m` | 前回のマニフェストの保存先（手元のキャッシュ）。省略すると `~/.cfs/cache/` に自動で作ります |
| `--output`, `-o` | アップロードしたマニフェストのハッシュを、このファイルに書き出します |

環境変数 `CFS_SIGNING_KEY` があれば、マニフェストに署名します（[設定](configuration.md#マニフェストの署名)）。

対象から外れるファイルは [制限と注意点](limitations.md#アップロードの対象から外れるファイル) を見てください。

### `merge`

```
cfs merge [-o ハッシュの出力先] 出力タグ ロケーション [ロケーション...]
```

複数のマニフェストをまとめて、新しいマニフェストを作り、`出力タグ` を付けます。同じパスがあるときは、**後ろに書いたものが優先**されます。ファイルの中身はキャビネットに既にあるので、アップロードし直しません。

例: 共通のアセットとプラットフォーム別のアセットをまとめる

```
cfs merge ios common ios-only
```

## ダウンロード・確認

### `sync`

```
cfs sync ロケーション 出力先フォルダ
```

マニフェストの全ファイルを、出力先フォルダに書き出します。中身はハッシュで照合してから書き出します。

- 出力先にある、一覧にないファイルは**消しません**
- ファイルの書き込みは、途中で失敗しても壊れたファイルが残らない方法で行います

### `ls`

```
cfs ls [--verify] ロケーション
```

マニフェストの中身を、パス・ハッシュ・サイズ・更新日時の順で表示します。ハッシュとサイズは、圧縮・暗号化する前の元のファイルのものです。

`--verify` を付けると、各ファイルの中身がダウンロード元に本当にあるかを確認し、`ok` / `ng` を表示します。

### `cat`

```
cfs cat ロケーション ファイルのパス
```

1つのファイルの中身を標準出力に表示します。主に確認用です。

### `config` / `setting`

今のアップロード先とダウンロード元（`config`）、キャッシュの置き場所（`setting`）を表示します。

### `http`

```
cfs http [-p ポート]
```

マニフェストの中身をブラウザで見られる、確認用の HTTP サーバーを `localhost` で起動します（既定のポートは 8000）。

- `http://localhost:8000/<タグ>/<パス>` でファイルを表示します。フォルダなら一覧を表示し、`index.html` があればそれを表示します
- サブドメインでタグを指定することもできます（`<タグ>.example.com`。ただし `cfs.` は特別扱いで無視します）
- `.htm` のファイルは、Excel が出力する HTML に合わせて Shift_JIS として返します

## キャビネットの管理

### `gc`

```
cfs gc [--dry-run] [--retention 期間]
```

どこからも使われなくなったマニフェストと中身を、キャビネットから消します。

- **残すもの**: すべてのタグが指すマニフェストと、保持期間（既定 30 日。`cfs cabinet config` で変更）内に作られたマニフェスト、およびそれらの中身
- **消すもの**: それ以外のマニフェストと、保持期間より古く、キャビネットに残っているどのマニフェストからも使われていない中身
- 消すのは、**前回の `gc` でも消す候補だったもの**だけです（2回続けて候補になったもの。前回から 1 時間以上あける必要があります）。アップロードの途中のものを消さないためです
- マニフェストを先に消し、その中身は後の回で消します。なので、使われなくなった中身が実際に消えるまでには、数回の `gc` が必要です
- 使われているマニフェストが1つでも読めないとき（鍵の設定が違うなど）は、何も消さずに止まります
- 消したものの一覧は、キャビネットの `gc/log/` に残ります

| オプション | 内容 |
|---|---|
| `--dry-run` | 何も消さず、消すはずのものを表示します |
| `--retention` | 保持期間を、今回だけ変えます（例: `14d`） |

定期的に（例: 1 日 1 回）実行してください。GitHub Actions の `schedule` などで動かせます。最初の数回は `--dry-run` で確かめると安心です。

### `tag`

```
cfs tag ls
cfs tag rm タグ [タグ...]
```

タグの一覧（名前、指しているマニフェストのハッシュ、更新日時）を表示します。`rm` はタグを消します。マニフェストと中身は、その後の `gc` で消えます。

### `cabinet`

```
cfs cabinet config
cfs cabinet config set retention 14d
```

キャビネットの設定（`config.json`）を表示・変更します。今のところ設定できるのは `retention`（GC の保持期間）だけです。

### `keygen`

```
cfs keygen
```

マニフェストに署名するための鍵の組を作り、表示します。使い方は [設定](configuration.md#マニフェストの署名) を見てください。

## パックファイル

詳しくは [パックファイル](pack-format.md) を見てください。

| コマンド | 内容 |
|---|---|
| `cfs pack 出力.tp フォルダ` | フォルダをパックファイルにまとめます |
| `cfs pack-manifest ロケーション 出力.tp` | キャビネット上のファイル一覧の中身をダウンロードして、パックファイルにまとめます |
| `cfs unpack 入力.tp` | パックファイルの中身を一覧表示します |
| `cfs unpack 入力.tp -o 出力先フォルダ` | パックファイルを展開します |
| `cfs patch 元.tp 新.tp 出力.tp` | 2つのパックファイルの差分だけを含むパックファイルを作ります |

## ファイルの絞り込み

グローバルオプションの `--filter-cmd` で指定します。`sync`、`merge`、`pack`、`unpack`、`pack-manifest` で使えます。

対象のファイルのパスを1行に1つずつ、指定したコマンドの標準入力に渡します。コマンドが標準出力に返した行のファイルだけを対象にします。

```
cfs --filter-cmd "grep ^sound/" sync v1 out
```

コマンドの文字列は空白で区切って実行するだけなので、引数を引用符で囲むことはできません。複雑な条件は、スクリプトにして呼び出してください。
