# 設定

CFS の設定は2種類あります。

| ファイル | 場所 | 形式 | 内容 |
|---|---|---|---|
| `.cfsenv` | コマンドを実行するフォルダ（`-C` で変更可） | JSON | プロジェクトごとの設定。アップロード先、ダウンロード元、圧縮、暗号化など |
| `.cfs_setting` | ホームフォルダ（`~/.cfs_setting`） | YAML | ユーザーごとの設定。キャッシュを置く場所 |

どちらも、なければ既定値で動きます。

## `.cfsenv`

```json
{
  "Cabinet": "s3://my-bucket",
  "Url": "https://cdn.example.com/",
  "Compress": true,
  "EncryptKey": "12345678901234567890123456789012",
  "EncryptIv": "1234567890123456"
}
```

キーの大文字・小文字は区別しません。

| キー | 既定値 | 内容 |
|---|---|---|
| `Cabinet` | `file:///var/cfs` | アップロード先の URL。`file://` と `s3://` が使えます |
| `Url` | （空） | ダウンロード元の URL。空なら `Cabinet` から自動で決まります（[ストレージ](storage-backends.md) を参照） |
| `Compress` | `true` | zlib で圧縮するか |
| `EncryptKey` | （空） | AES の鍵。16、24、32 バイトのどれか。空なら暗号化しません |
| `EncryptIv` | （空） | AES の IV。16 バイト |
| `Recursive` | `true` | サブフォルダも対象にするか |
| `Flatten` | `false` | `true` にすると、フォルダ構成を捨ててファイル名だけで管理します |
| `NoCache` | `false` | `true` にすると、`--force` と同じく手元のキャッシュを使わずに全ファイルを調べ直します |

コマンドラインの `--cabinet` / `-c` を指定すると、`Cabinet` を上書きできます。

### 圧縮と暗号化

- 順番は **zlib 圧縮 → AES-CFB 暗号化** です。戻すときは逆の順番です
- `Compress` が `true` なら圧縮し、`EncryptKey` が空でなければ暗号化します
- ただし、拡張子が **`.ab`、`.raw`、`.pbx`、`.mp4` のファイルは、設定にかかわらず圧縮も暗号化もしません**。Unity の AssetBundle や動画のように、容量が大きく、もともと圧縮されているものだからです。特に AssetBundle は、クライアントで読み込むたびに復号すると実行時のコストが高いので、意図的に暗号化していません。今のところ、この拡張子の一覧は変更できません
- どのファイルを圧縮・暗号化したかはファイル一覧に記録されるので、ダウンロードするときはファイルごとに正しく戻せます

**ダウンロードする側も、アップロードした側と同じ `Compress`、`EncryptKey`、`EncryptIv` が必要です。** ファイル一覧自体が、これらの設定で圧縮・暗号化されているためです。

> `EncryptKey` と `EncryptIv` は秘密にしたい情報です。`.cfsenv` をリポジトリにコミットする場合は、そのリポジトリを誰が読めるかに注意してください。

## `~/.cfs_setting`

```yaml
HomeRoot: D:/somewhere
```

| キー | 既定値 | 内容 |
|---|---|---|
| `HomeRoot` | ホームフォルダ | ここに `.cfs` フォルダ（キャッシュ置き場）を作ります。ホームフォルダの容量が少ないときに、別のドライブへ移せます |

`cfs setting` で、今の `HomeRoot` を確認できます。

## 手元のキャッシュ

| 場所 | 内容 |
|---|---|
| `~/.cfs/cache/` | `upload` のときに使う、前回のファイル一覧。アップロード先と対象フォルダの組み合わせごとに1つできます |
| `~/.cfs/datacache/` | ダウンロードしたファイルの中身（圧縮・暗号化されたまま） |

どちらも消して構いません。消した場合、次回の `upload` は全ファイルを読み直し（中身が同じならアップロードはしません）、`sync` は中身をダウンロードし直します。

`upload` の `-b` でファイル一覧の保存先を指定すると、`~/.cfs/cache/` の代わりにそこを使います。

`cfs config` で、今のアップロード先とダウンロード元を確認できます。
