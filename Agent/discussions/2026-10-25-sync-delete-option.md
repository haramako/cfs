# sync に、一覧にないファイルを消す --delete を足す

**状態: 実装済み（2026-10-25）。**

## 背景

`sync` は出力先にある、マニフェストにないファイルを消さない。オーナーから「既定で掃除するようにして、掃除しない挙動はオプションで。……逆のほうがいいかな？迷う」と相談があった。

## 検討

- 既定で消す: 出力先を間違えただけで（`cfs sync v1 .` など）、そのフォルダの中身を全部消してしまう
- 既定では消さず、オプションで消す: rsync（`--delete`）や aws s3 sync（`--delete`）と同じ
- 中間案: 前回 cfs が書いたファイルを出力先に記録しておき、それだけを消す。既定で消しても安全だが、記録ファイルの分だけ仕組みが増える

エージェントは「既定では消さず、`--delete` で消す」を勧め、**オーナーがそれを選んだ**。

## 決定事項

- `cfs sync --delete`: 書き出しが全部うまくいった後で、出力先にある一覧にないファイルと、それで空になったフォルダを消す（出力先のフォルダ自体は残す）
- `--filter-cmd` で絞ったときは、絞った後の一覧にないものを消す
- 比較は NFC にそろえ、Windows と macOS では大文字・小文字も区別しない（大文字だけ違う既存のファイルに書き出すと、名前が大文字のまま残るので、それを消さないため）
- 実装は `Downloader.RemoveUnlisted`
