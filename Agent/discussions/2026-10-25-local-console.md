# 手元向けの管理画面（cfs console）を足す

**状態: 実装済み（2026-10-25）。**

## 背景

オーナーから「`cfs serve` とは別に、今のタグの一覧とその中のファイルの情報を見るための管理コンソールを、localhost 向けの Web UI で追加して。暗号化キーは今指定されているもの前提でいい」と指示があった。

## 決定事項（エージェントが決めたこと）

- コマンドは `cfs console`、既定の待ち受けは `127.0.0.1:8001`（`serve` の 8000 の隣）
- 見るだけ（タグの削除や GC などの変更はしない）。変更の機能は、必要になったら相談する
- 画面は 2 つ: タグの一覧（ファイル数・大きさ・置いた大きさ・署名した鍵・更新日時、キャビネットの設定）と、マニフェストのファイル一覧（パス・大きさ・属性・更新日時・ハッシュ）。ファイル名から、復号した中身を開ける（`serve` の仕組みを使い回す）
- **安全のため、ループバックのアドレスでしか待ち受けず、`Host` が localhost 以外のリクエストは 403**。今の鍵で復号した中身を見せるので、ほかのサイトから DNS リバインディングで読まれないようにした
- 読めないマニフェスト（鍵が違うなど）は、ページ全体を失敗させず、その行にエラーを出す
- 画面の文言は、CLI の出力や `serve` の一覧に合わせて英語
- マニフェストに `SignedBy`（署名した鍵の ID）を持たせた（画面に出すため）

## 確認

テスト用のバケットで動かし、組み込みのブラウザでタグの一覧、マニフェストの中身、絞り込みを確かめた。鍵を渡さずに動かすと、テストで暗号化したタグの行に「wrong encryption key?」のエラーが出ることも確かめた。
